# Blog Drafts — How to Publish

5 SEO drafts targeting the competitor keywords. Each file has the content plus a header block with the admin fields.

## Publishing steps (admin → Blog → New)

For each file:

1. **Title** — the `# ` line (drop the `# `)
2. **Slug** — suggested: `vaishno-devi-yatra-guide-2026`, `kashmir-tour-package-from-delhi`, `vaishno-devi-hotel-booking-guide`, `best-time-to-visit-kashmir`, `jammu-to-katra-taxi-fare`
3. **Category** — from the `**Category:**` line (creates a blog category page automatically)
4. **Excerpt** — from the `**Excerpt:**` line
5. **Cover image** — the Unsplash URL (or upload your own photo)
6. **Content** — everything **below the `---`** line. Markdown supported: `## / ###` headings, `- ` lists, `| |` tables, `**bold**`, `[text](/link)` internal links, `> ` quotes
7. **Published** — toggle on, set publishedAt date

## Notes

- Internal links point to `/tours`, `/hotels`, `/taxi`, `/contact` — they only help SEO once published
- Prices/fares are 2026 market figures — sanity-check anything you know better before publishing
- Publish 1–2 per week rather than all at once; GSC indexing prefers steady cadence
- After publishing, request indexing in GSC for each URL
